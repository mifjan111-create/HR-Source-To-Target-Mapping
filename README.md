# HR-Source-To-Target-Mapping
HR data modernization project demonstrating source-to-target mapping, transformation logic, ETL validation, and reconciliation controls.

**HR Source-to-Target Mapping & ETL Validation**

**Business Problem**
As part of an HR data modernization initiative, employee data needed to be migrated from a legacy HR system into a centralized reporting environment. The project focused on documenting source-to-target mappings, defining transformation logic, establishing validation controls, and performing reconciliation checks to ensure data accuracy and reporting readiness.


**Project Objectives**

•	Define source-to-target mappings for HR data fields.

•	Document transformation and standardization rules.

•	Establish data validation controls.

•	Perform reconciliation checks between source and target systems.

•	Support HR reporting and analytics requirements

**Process Flow**

The project followed a structured ETL validation workflow:
1.	Legacy HR System
2.	Data Extraction
3.	Source-to-Target Mapping
4.	Transformation Rules
5.	Validation Checks
6.	Data Reconciliation
7.	HR Data Warehouse
8.	Power BI Reporting


   
**Deliverables**

**Source-to-Target Mapping Document**

Documented field-level mappings between the legacy HR system and the target reporting environment, including:

•	Source fields

•	Target fields

•	Data types

•	Transformation logic

•	Business rules



**Validation Framework**

Validation controls were defined to identify:

•	Duplicate Employee IDs

•	Missing Employee Names

•	Invalid Salary Values

•	Invalid Employment Statuses

•	Future Hire Dates

•	Record Count Mismatches



**Reconciliation Summary**

Source and target records were compared to confirm:

•	Record completeness

•	Data consistency

•	Migration accuracy



**Key Validation Rules**

**Validation Check	Expected Rule**

Employee ID	        Must be unique

Employee Name	      Cannot be blank

Salary	            Greater than 0

Employment Status  	Active, Leave, or Terminated

Hire Date	          Cannot be future dated

Record Count	      Source = Target
